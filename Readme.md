# E-Commerce Product Search

A product search interface built using HTML, CSS and JavaScript.

## Features

- Fetch products using Fetch API
- Product grid
- Debounced search
- Auto-suggestions
- Product thumbnails
- Product details
- Product image gallery
- Dynamic rating
- Add to Cart UI
- Buy Now UI

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON API

## Concepts Practiced

- DOM Manipulation
- Async/Await
- Fetch API
- Debouncing
- Array filter()
- Array slice()
- Event Handling
- Dynamic UI Rendering
